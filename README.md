# Sales Analysis Project 📊

## Overview

This project focuses on analyzing customer purchasing behavior using sales data. The objective of this analysis is to identify key business insights such as customer demographics, spending patterns, top-performing states, occupations, and product categories. The project was performed using Python libraries such as Pandas, NumPy, Matplotlib, and Seaborn in Jupyter Notebook.

---

## Dataset Information

The dataset contains customer sales records with details related to:

* User ID
* Customer Name
* Product ID
* Gender
* Age & Age Group
* Marital Status
* State & Zone
* Occupation
* Product Category
* Orders
* Amount Spent
* etc.

The dataset was cleaned and preprocessed before analysis by handling missing values, removing unnecessary columns, and preparing the data for visualization.

## Key Business Questions Analyzed

The project answers several important business questions:

### 1. Which Gender Buys the Most?

Analysis shows that **female customers** contribute more to total purchases and spending compared to male customers.

### 2. Which Age Group Buys the Most?

Customers in the **26–35 years** age group are the highest buyers and contribute the most revenue.

### 3. Which State Spends the Most?

The states with the highest customer spending are:

* Uttar Pradesh
* Maharashtra
* Karnataka

### 4. Are Married or Unmarried Customers Spending More?

The analysis indicates that **married customers**, especially married women, spend more compared to unmarried customers.

### 5. Which Occupation Spends the Most?

Customers working in:

* IT Sector
* Healthcare
* Aviation

have the highest purchasing power and spending behavior.

### 6. Which Product Category is Purchased the Most?

The most purchased product categories are:

* Clothing
* Electronics

## Overall Conclusion

**Married women aged 26–35 years from Uttar Pradesh, Maharashtra, and Karnataka working in IT, Healthcare, and Aviation are more likely to purchase products from the Clothing and Electronics categories.**

This analysis can help businesses improve marketing strategies, target the right audience, and increase sales performance.
